ORIGINAL EARTHQUAKE LOGIC:

The raw ADXL345 X/Y/Z values are converted using:

ax = raw_x * 0.0039f;
ay = raw_y * 0.0039f;
az = raw_z * 0.0039f;

Static gravity is estimated using a low-pass filter:

lowpass_x += FILTER_ALPHA * (ax - lowpass_x);
lowpass_y += FILTER_ALPHA * (ay - lowpass_y);
lowpass_z += FILTER_ALPHA * (az - lowpass_z);

Dynamic components:

dx = ax - lowpass_x;
dy = ay - lowpass_y;
dz = az - lowpass_z;

Vibration:

sqrtf(dx * dx + dy * dy + dz * dz)

Total acceleration:

sqrtf(ax * ax + ay * ay + az * az)

Detection:
Each sample is checked against 0.08 g.
The detector collects 10 samples.
If at least 8 of the 10 samples exceed the threshold, an earthquake event starts.
Do not change this logic unless absolutely required for Arduino compatibility.
